# Security policy

RadiusCore v0.1.0 is a development snapshot intended for lab use.

Report suspected vulnerabilities privately using [GitHub's vulnerability reporting form](https://github.com/tishriclarin/radiuscore/security/advisories/new). Include the affected commit or version, the relevant component, steps to reproduce, and the expected impact. Sanitize examples and remove credentials, NAS shared secrets, and subscriber data. Keep vulnerability details out of public issues and pull requests while the report is being addressed.
